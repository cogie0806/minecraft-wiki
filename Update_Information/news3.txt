Minecraft Java Edition 26.2「カオス・キューブド」アップデート解説

Minecraft Java Edition 26.2（通称「カオス・キューブド」）では、新たな地下バイオームやユニークなモブ、システム面での便利な機能が多数追加されました。主な変更点は以下の通りです。

1. 新バイオーム「硫黄の洞窟」と関連ブロック

オーバーワールドの地下深くに、新しいバイオームである「硫黄の洞窟」が生成されるようになりました。

硫黄の池: 黄色の液体で満たされた池で、足を踏み入れるとステータス効果「吐き気」が付与されます。

硫黄・辰砂: 新しい建材としても加工できるブロックが追加されました。

強力な硫黄: 硫黄を9個集めてクラフトできるブロックです。上に水を設置すると有毒ガスを発生させます。また、マグマブロックや溶岩源と組み合わせることで、エンティティを上空へ飛ばす「間欠泉」を作り出すことができます。

尖った硫黄: 硫黄の洞窟内の天井や床に自然生成される、鍾乳石や石筍に似たブロックです。先端が隣接すると自動的に結合し、落下するとダメージを受ける危険な性質も持っています。

2. 新モブ「サルファーキューブ」

硫黄の洞窟には、周囲のブロックを吸収する性質を持つ新しいモブ「サルファーキューブ」が生息しています。

原木や氷、鉄ブロックなどを取り込むことができ、取り込んだブロックによって挙動が変わります。

ハサミを使うことで、取り込まれたブロックを取り出すことが可能です。

倒すと小さなサルファーキューブに分裂し、スライムボールを与えることで成長させることができます。

3. システム・UIの変更点

フレンドリクエスト機能: Java版に待望のフレンド機能が実装されました。タイトル画面やポーズメニュー、あるいは「O」キーを押すことでフレンドリストの管理や申請の確認を行えます。

ゲームメニューの改善: 「フィードバックを送る」や「バグを報告する」などのボタンがアイコン化され、よりすっきりとした見た目になりました。

マルチプレイ・コマンドの調整: /publish コマンドでオンラインマルチプレイかローカルマルチプレイかを直接指定できるようになるなど、細かい利便性が向上しています。
